# Hero art

Drop official/menu art here as `<hero id>.webp` or `.png` (for example `spider-man.webp`, `jeff-the-land-shark.webp`).
Female Loki is `loki-female.webp`. Then run `npm run build:heroes` so `shared/fighters.json` picks it up.

Until a hero has an image, the site shows a type-colored badge with the hero's initials.
Hero ids are listed in `shared/fighters.json` (`"id"`).
